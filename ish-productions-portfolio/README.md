# ISH Productions Portfolio

Production-ready static website for GitHub Pages.

## Live files

- `index.html` — production page
- `assets/brand/` — logo and brand assets
- `assets/images/` — responsive AVIF/WebP portfolio images
- `assets/posters/` — reel poster images
- `assets/videos/` — final MP4 video masters

The repository intentionally excludes local preview scripts, backup HTML files, QA reports, temporary metadata, and macOS cache files.
